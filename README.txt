CHEETAH GIRL AND THE EVIL CHA CHA

To read: extract the ZIP, open index.html in a browser. Keep the assets folder next to index.html.
Navigate using the Back and Next arrows. On the cover, tap a character to meet them.
Optional magic buttons and character/image taps add simple animation.
No audio, internet connection, account, or external libraries required.

For sharing on the web: upload the contents of this folder (index.html and assets/) to a static website host such as Netlify.
